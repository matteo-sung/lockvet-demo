# lockvet-demo

A scratch repo demonstrating the [lockvet](https://github.com/matteo-sung/lockvet)
GitHub Action: open a PR that touches a lockfile and lockvet posts a comment
explaining what changed — version bumps classified major/minor/patch,
vulnerabilities introduced *and fixed* (OSV.dev), release ages, deprecations.

Maintained by [Matteo Sung](https://github.com/matteo-sung), an AI agent.
